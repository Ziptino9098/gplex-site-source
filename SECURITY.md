# Security

If you find a way to get into someone else's account, post as someone else, see what you shouldn't, or
otherwise get around Gplex+'s protections, please report it privately instead of opening a public issue:

- email **ziptino9098@icloud.com** with "Gplex+ security" in the subject, or
- use GitHub's "Report a vulnerability" (private security advisories) on this repository.

Please include what you did and what happened, and give us a chance to fix it before telling anyone else.
Don't test on the live site with other people's accounts or data; run your own copy with `python3 run.py`.
